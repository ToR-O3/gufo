## 分かった範囲

この比較では、DeltaNetの変更を外すと繰り返す記号による反復が改善した。一方、通常Attentionだけでも計算などの誤りが残り、共有エキスパートだけでも順序・言語の混入が残った。したがって「一群だけ戻せば完成」「壊れた1本を特定できた」とは結論しない。個々の層、相互作用、広い能力への影響は未特定。

無害な追加8問は未加工モデルも拒否しなかった。壊れた回答を拒否除去の成功には数えず、今回の結果から拒否抑制の効果を主張しない。5候補をこの短い試験だけに合わせて完成品として選ぶこともしない。各候補は1回の診断であり、正式な速度・長文・MTP・一般能力の評価ではない。
