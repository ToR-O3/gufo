精度と動作

  • 共有エキスパートの中間FP16値・出力FP32値：旧経路とビット単位で一致。1 / 8 / 9 / 32 / 33 / 129 / 257 / 4096行を検証。
  • CPUで復元した重みと検証済み中間値による独立FP64積和基準：相対RMS 2.0255×10⁻⁶、既存の上限2×10⁻⁵に合格。モデル全体の元の学習精度を保証する検査ではありません。
  • 実モデル136 tokenを一括／127+9に分割：選択した5位置（0 / 126 / 127 / 128 / 135）の層別トレースに数値差なし。
  • 32K・128K全測定の生成文・入出力token数が変更前後で一致。MTPの実際のdraft実行を確認。
  • 短文の同時2会話、seed固定の再生成、別会話からのキャッシュ再利用を確認。通常構成は変更前へ復旧。

キャッシュの監査

正式測定12件すべて cache_prompt=false、cached_tokens=0、cache_hit=false、復元バイト数0を確認しました。Prefill実行token数は常に入力token数と一致し、32Kは32,764、128Kは130,813 tokenを毎回全量処理しています。通常の保存処理は残していますが、保存済み会話を読み戻して入力処理を省略した結果ではありません。OSのファイルキャッシュやGPUの温度などの変動まで排除した試験ではありません。
