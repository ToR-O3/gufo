## 取り込み検査との区別

- 固定Qwen/Luniの64行列を全比較し、変更18本、微小差2本、同一44本を確認。
- 18本の量子化とDeltaNetの列順を確認。実書き込みを別実装gguf-pyで逆量子化した結果は、GGML C実装と全要素一致。
- 対象外のGGUFバイトと全テンソル構造は元Unslothと一致。
- これらは指定した差分を移植した検査であり、Luni自体や混合量子化との組み合わせの品質保証ではない。

[Luni公開議論 #1](https://huggingface.co/Luni/Qwen3.8-Flash-Next-Heretic-ARA/discussions/1) には、BF16の段階で品質が低下したという利用者報告と作者の返信がある。報告値を当方の測定として扱わず、「一部に壊れた重みが混入した」とも断定しない。どの変更や組み合わせが品質を落とすかは未確定。

## 終了状態と証跡
