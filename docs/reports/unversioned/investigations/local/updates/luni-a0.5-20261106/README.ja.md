試験全体（ローカル保管：runtime-result.json）、本文確認（ローカル保管：manual-review.json）、通常Gufoの復旧（ローカル保管：normal-restored.json）。品質不合格のため正式な速度測定、128K設定、MTP、外部Q8 PLEの候補試験には進んでいない。
