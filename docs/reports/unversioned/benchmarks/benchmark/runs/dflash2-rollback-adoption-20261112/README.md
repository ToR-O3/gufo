2026-11-12 JST。ToR-O3 UD-IQ4_XS＋内蔵PLE。gfx1151、WSL＋Docker、ROCm 10.1、`AMD_SERIALIZE_COPY=2`。⑤の信頼度カット `94028ef` を土台に、⑱のGDN状態と畳み込み履歴の融合復元をDFlash2の通常幅で有効にした。既存の短い巻き戻しループ、スナップショット、GPUストリームを使う。試験用の環境変数は検証ビルドのみにある。

## 全語彙ロジットとGDN状態の照合

同一の診断ビルドに、⑤単独の復元と⑤＋⑱の復元を用意した。固定幅7を上限として⑤の信頼度カットを使い、通常文、約13.5Kの長文、反復、温度0.7・シード4、RAMキャッシュの完全一致、ライブ再開、新規処理の16件を照合した。両構成で出力、ドラフト件数・採用数、キャッシュ経路、再利用量が一致した。正式の完全一致キャッシュでは13,458トークンを再利用して追加Prefillは0。ライブ再開は13,554トークンを再利用し、追加Prefillは26。

検証前の先頭ロジット704行、ペナルティ適用前の検証ロジット2,350行、保持した位置のロジット704行を全て比較した。合計3,758行、各248,320語、計933,186,560個のFP32値が有限で、バイト単位で一致。短い検証幅2〜8行で計332回の部分巻き戻しを通り、うち328回は同じ要求で続く生成の先頭ロジットも照合した。確認対象は同じ履歴・同じ検証経路での⑤と⑤＋⑱。GDN演算テストもgfx1151で通り、独立したCPUの積和式、復元した状態・履歴のバイト、履歴末尾のガードを確認した。

## 単独生成で常用MTPを上回った負荷

応答完了の中央値。各ケースはウォームアップを除き３組。２組はMTP→DFlash2、残り１組は逆順。定型文512トークンは、別の負荷を挟まずサーバー起動後の最初から反復の要求だけを送った。

| 負荷 | MTP | ⑤＋⑱ DFlash2 | 完了短縮 |
|---|---:|---:|---:|
| コードの部分編集 | 5.03秒 | 2.24秒 | 55.4% |
| JSONの部分編集 | 2.58秒 | 2.08秒 | 19.1% |
| 制約付きJSON | 4.02秒 | 3.44秒 | 14.3% |
| 定型文512トークンを最初に実行 | 9.97秒 | 8.55秒 | 14.3% |
| 他の負荷の後の定型文128トークン | 6.74秒 | 4.61秒 | 31.5% |
| RAMキャッシュ完全一致 | 4.31秒 | 4.02秒 | 6.9% |
| ライブキャッシュから続き | 4.96秒 | 4.60秒 | 7.3% |

上表はいずれも同じ入力の全３組で完了が短縮。通常文は3組ともMTPの完了が早く、1.6Kで5.26秒→5.50秒、13.5Kで15.56秒→17.03秒だった。日本語と新規コードはDFlash2がわずかに速く、完了中央値の短縮はそれぞれ4.1%と3.9%。思考ありは約0.7%。短いツール呼び出しとキャッシュ作成・再利用の最初の要求は組によって勝敗が変わった。

通常の比較42件と512トークン反復３件では、入力、出力、トークン数がすべて一致。ツールはSSEから引数を組み立てて照合した。RAMキャッシュ完全一致のDFlash2は２組で9〜10トークンを追加Prefillし、MTPは追加0。３組目は両構成とも追加0だった。このため、完全一致のDFlash2のTTFTは中央値で45→287 msと長く、Decodeの短縮で要求全体が速くなった。

各３組の中央値。左から常用MTP、⑤＋⑱ DFlash2。出力区間は早い方の初回出力から最後の応答まで、要求全体は早い方の送信から最後の応答まで。要求全体の合計速度は６組ともMTPが上回った。MTPは幅２でバッチ処理し、DFlash2は既存の逐次実行を使った。セッション別のTTFTとストリーミング間隔は全表に収録。12件とも出力と生成トークン数が一致した。

## 反復128トークンを最初に実行した対照

同じ定型文をサーバー起動後の最初の負荷にすると、128トークンの完了はMTPの4.05秒に対してDFlash2は4.36秒で、３組ともMTPが早かった。Decodeは69.58→82.09 tok/s、TTFTは2.17→2.74秒。ほかの負荷を先に実行した比較ではMTPのDecode中央値が29.98 tok/sまで下がった。どちらも候補159件、採用111件で、順序と履歴に依存する速度差の原因は今回特定していない。512トークンの反復は、最初の負荷でもDFlash2が全組で完了まで速かった。

同一ビルドのMTPで通常文・長文・反復も照合した。完了中央値は通常文が5.28→5.55秒、長文が15.32→16.36秒、ほかの負荷の後の反復が7.03→4.55秒。通常文は３組中２組、長文は全３組でMTPが先。反復は全３組でDFlash2が先。常用MTPとの正式60件と同一ビルドの正式９件で、対応する入力、出力、トークン数が一致した。
