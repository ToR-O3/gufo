# Stages移行後の速度調査

> この文書は各作業段階の記録です。最終判断（2026-11-27）はv0.37の採用保留・外部化見送り、通常利用はv0.36 main、キャッシュ上限4 GiBです。本文の当時の状態・計画・測定値は維持しています。ローカル生ログは同梱せず、公開用コピーでは利用者ホームパスを匿名化しています。
キャッシュ上限4 GiB。通常モデル、DFlash2、pp2048/tg128、同一HTTPハーネス。
非プロファイル計測: v0.36→v0.37→v0.37→v0.36、各サーバー暖機2回、正式3回、C1/C2を個別起動。各版各並行数6測定、合計36回答。準備・暖機は別途必要。
独立プロファイル: 両版C2、暖機1回・正式1回。生成区間と準備区間を混同しない。
既存バイナリを維持、製品コード変更なし。通常Gufoをdrainして測定中だけ停止し、finallyで同じ4 GiB通常設定に復帰。
完了判定: 実際の高速経路・カーネル選択を比較し、遅延が再現する区間と再現しない差を区別して記録する。原因を確定できなければ未特定とする。
