# カスタム台帳

このforkのv0.36、実装リビジョン53a217cbで採用しているカスタムをまとめています。モデル名ではなく重み形式と処理の役割を基準にしています。

## 検証範囲

主な実モデル検証はFlash-NextのUnsloth v3.1 IQ4_XS系です。対応コードがあることと、他の配布モデル・構造で実機検証したことは区別してください。Windows native、NPU、画像の実機合格をこの台帳から推定しないでください。

起動時だけの短縮より、通常の推論速度を優先します。公式で満たせる処理は公式へ寄せ、独自の再実装や不要なコピー・変換を増やしません。形式・処理に即した命名と既存コードの再利用を基本にします。
